마이크 확인 · 권한 도움말

권한 창은 Read 또는 마이크 확인을 눌렀을 때만 요청합니다.

  1. 배포한 HTTPS 주소를 Chrome 일반 탭에서 직접 열어 주세요. 파일 미리보기나 다른 앱 안의 화면에서는 제한될 수 있어요.
  2. 스마트패드 설정 → 애플리케이션 → Chrome → 권한 → 마이크에서 앱 사용 중에만 허용을 선택해 주세요.
  3. Chrome → 설정 → 사이트 설정 → 마이크에서 현재 사이트를 허용해 주세요. 기기 전체의 ‘마이크 액세스’도 켜져 있어야 해요.
  4. 마이크가 다른 앱에서 사용 중이면 그 앱을 닫아 주세요. 학교 관리 기기에서 설정이 잠겨 있으면 담당 선생님께 알려 주세요.

쉬운 판정: 단어의 절반 이상이 들리거나 물건 이름과 짧은 대답이 들리면 통과해요. 다른 물건 이름이나 반대 대답은 다시 읽어요. 재도전해도 별은 줄지 않아요.
자동 확인은 영어 단어를 알아듣는 활동이며 전문 발음 점수는 아니에요. 비슷하게 들린 물건 이름도 너그럽게 인정해요.
